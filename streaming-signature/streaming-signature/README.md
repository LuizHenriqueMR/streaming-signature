# Sistema de Assinatura de Streaming

Projeto desenvolvido em Java utilizando o padrão de projeto Decorator.

## Funcionalidades

- Assinatura base do streaming
- Adição de pacotes opcionais
- Cálculo automático do valor total
- Impedimento de pacotes duplicados

## Como executar

### Compilar
javac src/*.java

### Executar
java -cp src Main
